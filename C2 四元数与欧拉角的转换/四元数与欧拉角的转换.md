## 一、性质

### 1. 从复数出发：为什么要造四元数

二维旋转可以用复数表示。一个复数

$$z = a + bi \qquad (a, b \in \mathbb{R})$$

对应复平面上的一个点，乘上 $i$ 就相当于逆时针旋转 $90^\circ$，因为

$$i^2 = -1 .$$

也就是说：**复数这个代数结构本身就自带"旋转"的几何意义**。我们想把这套办法搬到三维：

$$q = a + bi + cj + dk \qquad (a,b,c,d \in \mathbb{R})$$

其中 $i, j, k$ 是三个虚数单位。

### 2. 先定 $ij = k$：为什么它不能是别的

板书是在这里停下来逐项试算、把 $ij$ 定下来的。**核心结论是：$ij$ 只能等于 $k$，不是人为规定出来的**。下面把这个"试算"完整写出来。

**前提（也就是 `ijk = -1` 那条约定要同时满足的条件）：**

1. $i, j, k$ 都是单位虚数：$i^2 = j^2 = k^2 = -1$，且 $\|i\| = \|j\| = 1$；
2. 乘法满足**结合律**与**分配律**；
3. 三维里没有第四个虚单位：$ij \in \operatorname{span}\{1, i, j, k\}$；
4. $q = a + bi + cj + dk$ 的共轭是 $q^{*} = a - bi - cj - dk$，且**共轭对乘法反序**：$(q_1q_2)^{*} = q_2^{*}q_1^{*}$。

**第一步：先算 $ij$ 与 $ji$ 的关系。**

现在取两个单位虚数 $i, j$。由前提 4（共轭对乘法反序）：

$$(ij)^{*} = j^{*}i^{*} = (-j)(-i) = ji$$

而共轭不改变模长（$\|q^{*}\| = \|q\|$），故 $\|ji\| = \|ij\|$。**也就是说：$ij$ 与 $ji$ 是两个互为共轭的四元数——实部相同、虚部相反。** 写开为

$$ij = a + bi + cj + dk \quad (a,b,c,d\in\mathbb{R}),\qquad ji = a - bi - cj - dk .$$

**第二步：实部 $a$ 必须是 $0$。**

$\|ij\| = \|i\|\|j\| = 1$，故

$$a^2 + b^2 + c^2 + d^2 = 1 .$$

下面逐个排除 $a \ne 0$ 的三种形式（$ij = a$、$ij = a+bj$、$ij = a + bi + cj$），用的都是同一招：**右边乘 $j$，然后比较实部/虚部系数**。

- 若 $ij = a$（纯实数，$a \ne 0$；此时 $j$ 的系数为 $0$）：由结合律 $(ij)j = i(jj)$，
  $$a\cdot j = i\cdot(-1) = -i \ \Longrightarrow\ aj = -i .$$
  右边 $j$ 的系数为 $a \ne 0$，左边（纯虚的 $-i$）的 $j$ 系数为 $0$，矛盾。**否决。**
- 若 $ij = a + bj$（$a \ne 0$）：
  $$-i = (a + bj)j = aj + b\,j^2 = aj - b .$$
  右边含 $aj \ne 0$，左边没有 $j$ 项。**否决。**
- 若 $ij = a + bi + cj$（$a \ne 0$，还带 $i$ 项）：
  $$-i = (a + bi + cj)j = aj + b\,(ij) - c = aj + b(a + bi + cj) - c = (ab - c) + b^2 i + (a + bc)j .$$
  比较实部与 $j$ 的系数：$0 = ab - c$ 且 $0 = a + bc$。代入 $c = ab$ 得 $0 = a + b(ab) = a(1 + b^2)$，因为 $a \ne 0$ 且 $1+b^2 > 0$，无解。**否决。**

三种含 $a \ne 0$ 的形式全部不成立，所以

$$\boxed{a = 0}\qquad\Longrightarrow\qquad ij = bi + cj + dk \ \text{（纯虚，且 } b^2+c^2+d^2 = 1\text{）}$$

**第三步：把 $ij$ 的两种纯虚可能逐个试掉。**

此时 $ij$ 是**单位纯虚四元数**，于是第一步的结论直接给出 $ji = \overline{ij} = -ij$，即

$$\boxed{ji = -ij}$$

**反交换律是被推出来的，不是额外假设。**

- 试 $ij = \alpha i + \beta j$（只含 $i, j$，没有 $k$）。右边乘 $j$：
  $$-i = \alpha\,(ij) + \beta\,j^2 = \alpha(\alpha i + \beta j) - \beta = -\beta + \alpha^2 i + \alpha\beta\,j .$$
  比较两边的实部、$i$ 的系数、$j$ 的系数：
  $$\text{实部：}\ 0 = -\beta;\qquad i\text{ 系数：}\ -1 = \alpha^2\ \text{（实数无解）};\qquad j\text{ 系数：}\ 0 = \alpha\beta .$$
  $i$ 的系数要求 $\alpha^2 = -1$，在 $\mathbb{R}$ 中无解。**否决。**
- 试 $ij = \gamma k$（只剩 $k$ 项，即 $\alpha = \beta = 0$、$\gamma = \pm 1$）。

  两个不同的虚单位相乘结果反交换（前面得到 $ji = -ij$ 的论证对 $j,k$ 同样成立），即 $kj = -jk$。代入 $ij = \gamma k$ 检验结合律 $(ij)j = i(jj)$：
  $$(ij)\cdot j = \gamma\,(kj) = -\gamma\,(jk), \qquad\text{而}\qquad i(jj) = -i ,$$
  两边相等即 $jk = \gamma\, i$（用 $\gamma^2 = 1$ 整理）。（这一步只用到反交换，还没有用到 $ijk$。）

  现在用 $ijk = -1$ 定 $\gamma$：
  $$ijk = (ij)k = \gamma k\cdot k = -\gamma \ \overset{!}{=}\ -1 \ \Longrightarrow\ \gamma = 1 . \quad\checkmark$$

  顺带得到 $kj = -i$、$jk = i$，与反交换自洽。

**所以**

$$\boxed{ij = k}$$

**第四步：由 $ij = k$ 得到整张乘法表。**

用 $ijk = -1$ 两边左乘 $i$ 的逆（$-i$，因为 $i^{-1} = -i$）得 $jk = i$；两边右乘 $k$ 的逆得 $ij = k$（自洽）；同理 $ki = j$。再加上第三步推得的一般反交换 $ji = -ij$：

$$ji = -k,\qquad kj = -i,\qquad ik = -j .$$

**完整的乘法规则与"换序要变号"**（反对称）：

$$\boxed{i^2 = j^2 = k^2 = ijk = -1}$$

$$ij = k,\quad jk = i,\quad ki = j \qquad(\text{正循环})$$
$$ji = -k,\quad kj = -i,\quad ik = -j \qquad(\text{逆序变号})$$

> 注意：$ji = -ij \ne ij$，所以**四元数乘法不满足交换律**。这一点后面解决球面插值、姿态复合的顺序问题时非常关键（和 C1 里矩阵乘法不可交换是同一件事）。

> **板书对应**：板书是在 $ij = a + bi + cj$ 这种形式下反复代入、比对实部与虚部系数，最后定出"$j$ 的系数为 $-1$"从而得到 $ij = k$。本文第二、三步用的是同一套"设－代入－比系数"的手法，只是把 $k$ 项也一起保留、并把结合律检验补齐。
>
> ⚠️ 板书这一步的中间行字迹较潦草（照片上难以完全辨认），**以本文上面的推导为准**。

### 3. 三种写法

| 写法 | 形式 | 说明 |
| --- | --- | --- |
| 代数式 | $q = a + bi + cj + dk$ | 最直观 |
| 四维列向量 | $q = \begin{pmatrix} a \\ b \\ c \\ d \end{pmatrix}$ | 便于写成矩阵乘法 |
| **标量 + 向量** | $q = [a, \vec{v}],\ \ \vec{v} = \begin{pmatrix} b \\ c \\ d \end{pmatrix}$ | **后面推导最常用** |

其中 $a$ 叫**实部（标量部分）**，$\vec{v}$ 叫**虚部（向量部分）**。约定记法：$[s, \vec{v}]$，$s$ 是标量，$\vec{v}$ 是三维向量。四个实数 $a, b, c, d$ 都在 $\mathbb{R}$ 中取值。

### 4. 模长

按四维向量的欧氏范数（也是"平方和开根"）：

$$\|q\| = \sqrt{a^2 + b^2 + c^2 + d^2} = \sqrt{a^2 + \|\vec{v}\|^2}$$

这是以后做**归一化**的依据：姿态解算里每步积分完都要把四元数拉回单位长度。

### 5. 加减法与标量乘法

**加减法**：对应分量相减加，即对每个分量分别运算。设 $q_1 = [s, \vec{v}_1]$，$q_2 = [t, \vec{u}]$：

$$q_1 \pm q_2 = [s \pm t,\ \vec{v}_1 \pm \vec{u}]$$

**标量乘法**（与实数 $s$ 相乘，可交换）：

$$s q = q s = sa + sb\,i + sc\,j + sd\,k$$

也就是每个分量都乘 $s$。线性结构（加减、数乘）与普通四维向量完全一样 —— **四元数的新东西全在"乘法"上**。

### 6. 四元数乘法（格拉斯曼积）

设

$$q_1 = a + bi + cj + dk,\qquad q_2 = e + fi + gj + hk .$$

直接按分配律展开（$16$ 项），用 $i^2=j^2=k^2=-1$、$ij = k,\ ji = -k$、$jk = i,\ kj = -i$、$ki = j,\ ik = -j$ 逐项化简：

$$
\begin{aligned}
q_1 q_2 &= (a + bi + cj + dk)(e + fi + gj + hk) \\
&= (ae - bf - cg - dh) \\
&\quad {} + (be + af - dg + ch)\,i \\
&\quad {} + (ce + df + ag - bh)\,j \\
&\quad {} + (de - cf + bg + ah)\,k .
\end{aligned}
$$

写成**矩阵 × 向量**的形式（列向量约定）：

$$
q_1 q_2 =
\begin{pmatrix}
 a & -b & -c & -d \\
 b &  a &  d & -c \\
 c & -d &  a &  b \\
 d &  c & -b &  a
\end{pmatrix}
\begin{pmatrix} e \\ f \\ g \\ h \end{pmatrix}
$$

> 板书写的是 $q_2$ 在右、矩阵在左、结果为一个四维列向量：**"乘 $q_1$"这个操作本身是一个线性变换**。
>
> ⚠️ 这里三个符号习惯的差别（$d$ 的符号、$c$ 与 $d$ 的行、第二行第三列）在教材之间不统一，取决于把 $q_1q_2$ 写成"左乘 $q_1$"还是"右乘"以及 $i,j,k$ 循环方向。**建议只记下面的向量公式 (1)，矩阵形式遇到时按同一约定现场展开核对。**

**向量形式的格拉斯曼积（重点）**：设 $q_1 = (a, \vec{v})$，$q_2 = (e, \vec{u})$，其中

$$\vec{v} = (b, c, d),\qquad \vec{u} = (f, g, h) .$$

把上面四个分量按"实部/虚部"重新分组：实部是 $ae - (bf + cg + dh)$，正是
$\vec{v}\cdot\vec{u}$；虚部三项分别来自
$$e\vec{v} \quad(\text{来自 } a e + be\,i + ce\,j + de\,k \text{ 中的后半})\text{、} a\vec{u}\text{、}\vec{v}\times\vec{u},$$
其中叉乘按行列式展开：

$$\vec{v}\times\vec{u} =
\begin{vmatrix}
 \mathbf{i} & \mathbf{j} & \mathbf{k} \\
 b & c & d \\
 f & g & h
\end{vmatrix}
= (ch - dg)\,\mathbf{i} - (bh - df)\,\mathbf{j} + (bg - cf)\,\mathbf{k} .$$

对照 $i, j, k$ 三个分量的系数即可核对（例如 $k$ 的系数：$de - cf + bg + ah$，而 $(\vec{v}\times\vec{u})_k = bg - cf$，差的 $de + ah$ 正来自 $e\vec{v} + a\vec{u}$ 的 $k$ 分量 $de + ah$ ✓）。于是：

$$
\boxed{\;
q_1 q_2 = \big[\;\underbrace{ae - \vec{v}\cdot\vec{u}}_{\text{实部}},\;\underbrace{a\vec{u} + e\vec{v} + \vec{v}\times\vec{u}}_{\text{虚部}}\;\big]
\;}\tag{1}
$$

**这就是格拉斯曼积**。它把"内积"和"外积（叉乘）"同时装进了一个乘法里 —— 这也是别的地方（比如 Clifford 代数、外积代数）都从 $\vec{v}\times\vec{u}$ 这一项出发的原因。

> ⚠️ 注意虚部里 $\vec{v}\times\vec{u}$ 的**顺序不能反**，反了就等于取负（四元数不可交换的根源）。

### 7. 纯四元数：实部为 0

若 $q_1$、$q_2$ 的实部都为 $0$，即 $a = e = 0$，则 (1) 式中 $ae = a\vec{u} = e\vec{v} = 0$，只剩下：

$$q_1 q_2 = \big[-\vec{v}\cdot\vec{u},\ \vec{v}\times\vec{u}\big]\tag{2}$$

（对应板书写的"实部为 $0$ 的情形"。）

这条式子说明：**两个三维向量的"内积 + 叉乘"运算，可以统一表示成两个纯四元数的乘积**。它是历史上四元数 → 向量代数 → 内积/叉乘的源头。

### 8. 共轭、逆与范数

#### (a) 共轭

$$\boxed{q^{*} = a - bi - cj - dk = [a, -\vec{v}]}$$

（虚部整体变号，实部不变。）板书把复数的情况作为对照：$a + bi$ 的共轭是 $a - bi$，两者相乘得到模长平方 $a^2 + b^2$ —— 四元数的共轭就是把这件事搬到四维。

> 记号说明：本节用 $q^{*}$（共轭）与 $q^{-1}$（逆）。板书上也写成 $\bar q$，两者是同一个东西；后面的姿态解算代码里常见 `conj(q)` 或 `q.conjugate()`。

**两个基本性质：**

$$(q^{*})^{*} = q \qquad（\text{共轭两次复原}）$$

$$
\begin{aligned}
q q^{*} &= [a, \vec{v}]\cdot[a, -\vec{v}] \\
&= \big[\,a\cdot a - \vec{v}\cdot(-\vec{v}),\ \ a(-\vec{v}) + a\vec{v} + \vec{v}\times(-\vec{v})\,\big] \\
&= \big[\,a^2 + \vec{v}\cdot\vec{v},\ \ \mathbf{0}\,\big] \\
&= a^2 + b^2 + c^2 + d^2 = \|q\|^2 .
\end{aligned}
$$

这里两个关键点：$a\cdot a - \vec{v}\cdot(-\vec{v}) = a^2 + \|\vec{v}\|^2$ 得到纯实数；而 $\vec{v}\times\vec{v} = \mathbf{0}$（叉乘自身为零）恰好让虚部**全部消掉**。所以

$$\boxed{q q^{*} = q^{*} q = \|q\|^2}$$

也就是说：**四元数与自己的共轭相乘，得到一个实数（模长平方）** —— 这正是复数 $z\bar z = |z|^2$ 的直接推广。

#### (b) 逆：由 $q q^{-1} = 1$ 解出

逆的定义是

$$q q^{-1} = 1 \qquad (q \ne \mathbf{0})$$

两边同时左乘 $q^{*}$：

$$q^{*}(q q^{-1}) = q^{*} \quad\Longrightarrow\quad (q^{*}q)\,q^{-1} = q^{*} \quad\Longrightarrow\quad \|q\|^2 q^{-1} = q^{*}$$

（注意实数 $\|q\|^2$ 与四元数可交换，且 $q^{*}q = \|q\|^2$。）

于是

$$\boxed{\;q^{-1} = \frac{q^{*}}{\|q\|^{2}}\;}\tag{4}$$

**特例（很常用）：若 $\|q\| = 1$，即 $q$ 是单位四元数，则**

$$\boxed{q^{-1} = q^{*}}$$

这是一个极其重要的简化：**单位四元数的逆就等于共轭**（只改虚部符号，不用除法）。姿态解算里我们只使用单位四元数，所以求逆是零代价的。

#### (c) 模长公式（拉格朗日四平方恒等式）

把 $\|q_1q_2\|^2 = \|q_1\|^2\|q_2\|^2$ 展开（四元数乘法保持模长，见下面第二节），并对每个分量用格拉斯曼积 (1) 展开，就得到板书上写的那个"大式子"：

$$
\begin{aligned}
&(a_1^2 + a_2^2 + a_3^2 + a_4^2)(b_1^2 + b_2^2 + b_3^2 + b_4^2) \\
=\;& (a_1b_1 - a_2b_2 - a_3b_3 - a_4b_4)^2 \\
&+ (a_1b_2 + a_2b_1 + a_3b_4 - a_4b_3)^2 \\
&+ (a_1b_3 - a_2b_4 + a_3b_1 + a_4b_2)^2 \\
&+ (a_1b_4 + a_2b_3 - a_3b_2 - a_4b_1)^2 .
\end{aligned}
$$

**这就是拉格朗日四平方恒等式**：两个"四个平方数之和"的乘积，仍然可以写成"四个平方数之和"。它本质上就是"四元数乘法保模长"这条代数性质写开来 —— 所以范数不只是在四元数上定义的，它是**在这个乘法下相容的**（四元数构成一个可除代数）。

## 二、与 3D 旋转

### 1. 单位四元数 ↔ 旋转矩阵

设单位四元数（$a^2 + b^2 + c^2 + d^2 = 1$）

$$q = a + bi + cj + dk = [a, \vec{v}],\qquad \vec{v} = (b, c, d)$$

**思路**：把 $R$ 看作一个线性变换，去求它的三个列向量。旋转的"夹三明治"形式是

$$R\vec{p} \;\longleftrightarrow\; q\,[0,\vec{p}]\,q^{-1} = q\,[0,\vec{p}]\,q^{*}$$

对任一向量 $\vec{p}$，按 (1) 式的格拉斯曼积把 $q\,[0,\vec{p}]\,q^{*}$ 的两步相乘展开（第一步 $q[0,\vec{p}]$ 用 (1) 式、第二步左乘 $[a,-\vec{v}]$ 再用一次 (1) 式，并整理 $(\vec{v}\times\vec{p})\times\vec{v}$ 一项），虚部可以整理成

$$R\vec{p} = \big(a^2 - \|\vec{v}\|^2\big)\vec{p} + 2(\vec{v}\cdot\vec{p})\,\vec{v} + 2a\,(\vec{v}\times\vec{p})$$

把三项分别化成矩阵形式：第一项 $(a^2 - \|\vec{v}\|^2)I$；第二项 $2(\vec{v}\cdot\vec{p})\vec{v} = 2\vec{v}\vec{v}^{\mathsf T}\vec{p}$；第三项 $2a\,(\vec{v}\times\vec{p}) = 2a\,[\vec{v}]_{\times}\vec{p}$，这里 $[\vec{v}]_{\times}$ 是叉乘的反对称矩阵，满足 $[\vec{v}]_{\times}\vec{p} = \vec{v}\times\vec{p}$（它就是 (1) 式中"$\vec{v}\times\vec{u}$ 对 $\vec{u}$ 线性"这件事的矩阵写法）：

$$[\vec{v}]_{\times} = \begin{pmatrix} 0 & -d & c \\ d & 0 & -b \\ -c & b & 0\end{pmatrix}$$

所以由 $q$ 表示的旋转矩阵是（下面还用单位条件 $a^2 + \|\vec{v}\|^2 = 1$ 把 $a^2 - \|\vec{v}\|^2$ 换成 $2a^2 - 1$）：

$$R = \big(a^2 - \|\vec{v}\|^2\big)I + 2\vec{v}\vec{v}^{\mathsf T} + 2a[\vec{v}]_{\times}
\;=\; (2a^2 - 1)I + 2\vec{v}\vec{v}^{\mathsf T} + 2a[\vec{v}]_{\times}$$

展开成分量：

$$
R=\begin{pmatrix}
1 - 2(c^2+d^2) & 2(bc - ad) & 2(bd + ac) \\
2(bc + ad) & 1 - 2(b^2+d^2) & 2(cd - ab) \\
2(bd - ac) & 2(cd + ab) & 1 - 2(b^2+c^2)
\end{pmatrix}
$$

> ⚠️ **符号约定提醒**：若把上面矩阵中的**虚部整体取负**（即用 $\vec{v}\to-\vec{v}$），除 $R^{\mathsf T}$ 之外元素全部相同：
> $$R^{\mathsf T}=\begin{pmatrix}1-2(c^2+d^2) & 2(bc+ad) & 2(bd-ac)\\ 2(bc-ad)&1-2(b^2+d^2)&2(cd+ab)\\ 2(bd+ac)&2(cd-ab)&1-2(b^2+c^2)\end{pmatrix}$$
> 这两者的差别**只是"$b\to e$ 的旋转"还是"$e\to b$ 的旋转"**，也就是 $R_b^e$ 还是 $R_e^b$。板书上矩阵的 $\pm$ 号跟教材/讲义里的定义有关，**用之前一定先拿一个已知例子（比如绕 $z$ 转 $90^\circ$）验一遍**，不要靠背。

### 2. 怎么用四元数转一个向量（罗德里格斯公式的“配方式”证明）

C1 已经得到罗德里格斯公式：

$$\vec{v}' = \cos\theta\,\vec{v} + (1-\cos\theta)(\vec{v}\cdot\vec{u})\vec{u} + \sin\theta(\vec{u}\times\vec{v})$$

现在用四元数算同一个东西：绕单位轴 $\vec{u}$ 转角度 $\theta$，取

$$q = \Big[\cos\frac{\theta}{2},\ \sin\frac{\theta}{2}\,\vec{u}\Big],\qquad \vec{v}' = q\,\vec{v}\,q^{-1} = q\vec{v}q^{*} .$$

（这里把 $\vec{v}$ 看成纯四元数 $[0,\vec{v}]$。）

**第一步，先算 $q p$**（$p = [0,\vec{p}]$，$q = [a,\vec{w}]$，$a=\cos\frac\theta2$，$\vec{w} = \sin\frac\theta2\vec{u}$）。由格拉斯曼积 (1)：

$$qp = \big[a\cdot 0 - \vec{w}\cdot\vec{p},\ \ a\vec{p} + 0\cdot\vec{w} + \vec{w}\times\vec{p}\big] = \big[-\vec{w}\cdot\vec{p},\ a\vec{p} + \vec{w}\times\vec{p}\big]$$

**第二步，再右乘 $q^{*} = [a, -\vec{w}]$**：设 $qp = [s, \vec{z}]$，其中 $s = -\vec{w}\cdot\vec{p}$，$\vec{z} = a\vec{p} + \vec{w}\times\vec{p}$，则

$$(qp)q^{*} = \big[\,sa - \vec{z}\cdot(-\vec{w}),\ \ s(-\vec{w}) + a\vec{z} + \vec{z}\times(-\vec{w})\,\big]$$

**第三步，只看虚部**（实部先放一边，看看结果对不对）：

$$
\begin{aligned}
\text{虚部} &= -s\vec{w} + a\big(a\vec{p} + \vec{w}\times\vec{p}\big) - \big(a\vec{p} + \vec{w}\times\vec{p}\big)\times\vec{w} \\
&= a^2\vec{p} + a\,\vec{w}\times\vec{p} + (\vec{w}\cdot\vec{p})\vec{w} - a\,\underbrace{\vec{p}\times\vec{w}}_{=-\vec{w}\times\vec{p}} - \underbrace{(\vec{w}\times\vec{p})\times\vec{w}}_{\vec{p}\,(\text{与 }\vec{w}\text{ 共面部分})}
\end{aligned}
$$

其中用了 $s = -\vec{w}\cdot\vec{p}$，以及 BAC-CAB 公式

$$(\vec{w}\times\vec{p})\times\vec{w} = \vec{p}\,(\vec{w}\cdot\vec{w}) - \vec{w}\,(\vec{w}\cdot\vec{p}) = |\vec{w}|^2\vec{p} - (\vec{w}\cdot\vec{p})\vec{w},$$

这里 $\vec{w} = \sin\frac\theta2\,\vec{u}$ 是**平行于旋转轴、长度为 $\sin\frac\theta2$** 的向量（不是单位向量，所以要老老实实写 $|\vec{w}|^2$）。代入 $a = \cos\frac\theta2$、$|\vec{w}| = \sin\frac\theta2$：

$$
\text{虚部} = \big(a^2 - |\vec{w}|^2\big)\vec{p} + 2a\,\big(\vec{w}\times\vec{p}\big) + 2(\vec{w}\cdot\vec{p})\,\vec{w}
$$

再代回 $a = \cos\frac\theta2$、$\vec{w} = \sin\frac\theta2\vec{u}$，用倍角公式 $a^2 - |\vec{w}|^2 = \cos^2\frac\theta2 - \sin^2\frac\theta2 = \cos\theta$、$2a|\vec{w}| = 2\sin\frac\theta2\cos\frac\theta2 = \sin\theta$：

$$\vec{v}' = \cos\theta\,\vec{v} + (1-\cos\theta)(\vec{v}\cdot\vec{u})\vec{u} + \sin\theta\,(\vec{u}\times\vec{v})$$

**与罗德里格斯公式完全一致 ✓**

> **这个证明给了两个很重要的结论：**
>
> 1. **旋转公式里出现的是半角** $\frac\theta2$。四元数之所以用 $\cos\frac\theta2,\sin\frac\theta2\vec{u}$ 而不是 $\theta$，就是为了让"夹三明治"（两次相乘）恰好给出 $\theta$。这也是后面欧拉角转换全是"半角"、"二倍角"的原因。
> 2. **$q$ 与 $-q$ 表示同一个旋转**（因为 $(-q)\vec{v}(-q)^{*} = q\vec{v}q^{*}$）。也就是说四元数到旋转是 **2 对 1** 的覆盖（$S^3 \to SO(3)$，双覆盖）。工程上常约定 $a \ge 0$ 取"同一个姿态的同一个四元数"；插值时要先判断符号是否同侧（取点积为负时先取负）。

### 3. 为什么这里值得停下来

- C1 的**旋转矩阵**：$9$ 个数，但只有 $3$ 个自由度（正交约束 $R^{\mathsf T}R = I$）；做复合是矩阵乘法，$27$ 次乘法；**万向锁**来自欧拉角，矩阵本身没有奇异。
- C1 的**轴角法**：奇点在 $\theta = 0$（转 $0^\circ$ 时"轴"没有定义），而且不好插值。
- **四元数**：$4$ 个数 + 一条约束 $\|q\|^2 = 1$，仍然是 $3$ 个自由度；复合就是四元数乘法（$16$ 次乘加）；**表示本身没有奇点**（$\theta = 0$ 时 $q = [1,\vec{0}]$ 完全正常），插值走单位球面上的大圆（SLERP）天然平滑。

> **注意**："四元数没有万向锁"是指**四元数表示本身**没有奇点。但只要你还得从姿态里"读出欧拉角"给人看/给控制器用，就必须做"四元数 → 欧拉角"这一步，**这一步仍然会碰到万向锁**。这正是下一节要讲的事，也是为什么"四元数没用上"往往是伪命题 —— 问题出在反解欧拉角，而不在四元数。

## 三、与欧拉角的转换

### 1. 约定

用 C1 的约定：从机体系 $b$ 到地球系 $e$ 的旋转矩阵是 ZYX 顺序（先绕 $Z$ 偏航 $\psi$，再绕 $Y$ 俯仰 $\theta$，最后绕 $X$ 横滚 $\phi$，"先发生的写在右边"）：

$$R = R_b^e = R_z(\psi)\,R_y(\theta)\,R_x(\phi)$$

$$R_z(\psi)=\begin{pmatrix}\cos\psi&-\sin\psi&0\\ \sin\psi&\cos\psi&0\\ 0&0&1\end{pmatrix},\quad
R_y(\theta)=\begin{pmatrix}\cos\theta&0&\sin\theta\\ 0&1&0\\ -\sin\theta&0&\cos\theta\end{pmatrix},\quad
R_x(\phi)=\begin{pmatrix}1&0&0\\ 0&\cos\phi&-\sin\phi\\ 0&\sin\phi&\cos\phi\end{pmatrix}$$

逐步乘出来：

$$
R = \begin{pmatrix}
\cos\psi\cos\theta & \cos\psi\sin\theta\sin\phi - \sin\psi\cos\phi & \cos\psi\sin\theta\cos\phi + \sin\psi\sin\phi \\
\sin\psi\cos\theta & \sin\psi\sin\theta\sin\phi + \cos\psi\cos\phi & \sin\psi\sin\theta\cos\phi - \cos\psi\sin\phi \\
-\sin\theta & \cos\theta\sin\phi & \cos\theta\cos\phi
\end{pmatrix}\tag{3}
$$

### 2. 从 (3) 反解欧拉角

在**非奇异**的情况下（$\cos\theta \ne 0$），对照 (3) 的各个元素：

| 需要的量 | 用哪些元素 | 结果 |
| --- | --- | --- |
| $\sin\theta$ | $R_{31}$ | $\sin\theta = -R_{31}$ |
| $\psi$（Yaw） | $R_{11}, R_{21}$ | $\psi = \operatorname{atan2}\!\big(R_{21},\ R_{11}\big)$ |
| $\theta$（Pitch） | $R_{31}$ | $\theta = \arcsin\!\big(-R_{31}\big)$ |
| $\phi$（Roll） | $R_{32}, R_{33}$ | $\phi = \operatorname{atan2}\!\big(R_{32},\ R_{33}\big)$ |

（$R_{ij}$ 表示第 $i$ 行第 $j$ 列。）

**为什么 Pitch 只能用 $\arcsin$、必须配 $\operatorname{atan2}$？**
若用 $R_{21}/R_{11} = \tan\psi$ 那样的写法，$\tan\theta$ 就会同时牵扯 $R_{11}$ 与 $R_{21}$，还得除 $\cos\psi$。用 $\arcsin(-R_{31})$ 能**一步拿到 $\theta$**，但 $\arcsin$ 的值域只是 $[-\frac\pi2, \frac\pi2]$ —— 对**四轴**来说这正好够用（四轴不会翻过头 $\theta = \pm 90^\circ$ 以上，翻了就掉下来了，而且这也是万向锁的位置）；但对通用刚体要小心多解。

### 3. 从四元数直接得到欧拉角（本节重点）

现在把两条链条接起来。单位四元数

$$q = a + bi + cj + dk = [a,\ \vec{v}]$$

总是可以写成（绕单位轴 $\vec{u}$ 转角度 $\Theta$，由第二节的旋转公式反推）

$$q = \Big[\cos\frac{\Theta}{2},\ \sin\frac{\Theta}{2}\,\vec{u}\Big],$$

则前面第二节的矩阵展开式给出

$$
R = \begin{pmatrix}
1 - 2(c^2 + d^2) & 2(bc - ad) & 2(bd + ac) \\
2(bc + ad) & 1 - 2(b^2 + d^2) & 2(cd - ab) \\
2(bd - ac) & 2(cd + ab) & 1 - 2(b^2 + c^2)
\end{pmatrix}\tag{5}
$$

**只要让 (5) 与 (3) 逐元素相等**，就能读出欧拉角：

**（i）Pitch。** 比较 $R_{31}$：

$$-\sin\theta = 2(bd - ac)\ \Longrightarrow\ \boxed{\ \theta = \arcsin\big(2(ac - bd)\big)\ }$$

**（ii）Yaw。** $R_{21}$ 与 $R_{11}$ 之比：

$$\frac{R_{21}}{R_{11}} = \frac{2(bc+ad)}{1-2(c^2+d^2)} = \frac{\sin\psi\cos\theta}{\cos\psi\cos\theta} = \tan\psi$$

$$\boxed{\ \psi = \operatorname{atan2}\big(2(ad + bc),\ 1 - 2(c^2 + d^2)\big)\ }$$

**（iii）Roll。** $R_{32}$ 与 $R_{33}$ 之比：

$$\frac{R_{32}}{R_{33}} = \frac{2(cd+ab)}{1-2(b^2+c^2)} = \frac{\cos\theta\sin\phi}{\cos\theta\cos\phi} = \tan\phi$$

$$\boxed{\ \phi = \operatorname{atan2}\big(2(ab + cd),\ 1 - 2(b^2 + c^2)\big)\ }$$

> 用 $\operatorname{atan2}(y, x)$ 而不是 $\arctan(y/x)$，是因为它同时看 $y$、$x$ 的正负号，值域扩展到 $(-\pi, \pi]$，能自动分辨"$+x$ 方向"和"$-x$ 方向"，避免丢象限。

### 4. 反向：从欧拉角得到四元数

**（a）由 $\psi, \theta, \phi$ 直接算 $q$。** 反向推导用的是**四元数乘法的复合**（等价于 C1 里"矩阵复合"那一套，只是换成四元数）：

$$\text{先绕 } Z \text{ 转 } \psi \ \Longrightarrow\ q_z = \Big[\cos\frac\psi2,\ 0,\ 0,\ \sin\frac\psi2\Big]$$
$$\text{再绕 } Y \text{ 转 } \theta \ \Longrightarrow\ q_y = \Big[\cos\frac\theta2,\ 0,\ \sin\frac\theta2,\ 0\Big]$$
$$\text{最后绕 } X \text{ 转 } \phi \ \Longrightarrow\ q_x = \Big[\cos\frac\phi2,\ \sin\frac\phi2,\ 0,\ 0\Big]$$

按 C1 得出的**外旋/内旋组合次序**（"先发生的写在右边"），ZYX 顺序相应地是

$$q = q_z\, q_y\, q_x$$

展开（三次用格拉斯曼积 (1)，或者直接用上面 (5) 式反算矩阵元素）得到：

$$
\boxed{
\begin{aligned}
a &= \cos\tfrac\psi2\cos\tfrac\theta2\cos\tfrac\phi2 + \sin\tfrac\psi2\sin\tfrac\theta2\sin\tfrac\phi2 \\
b &= \cos\tfrac\psi2\cos\tfrac\theta2\sin\tfrac\phi2 - \sin\tfrac\psi2\sin\tfrac\theta2\cos\tfrac\phi2 \\
c &= \cos\tfrac\psi2\sin\tfrac\theta2\cos\tfrac\phi2 + \sin\tfrac\psi2\cos\tfrac\theta2\sin\tfrac\phi2 \\
d &= \sin\tfrac\psi2\cos\tfrac\theta2\cos\tfrac\phi2 - \cos\tfrac\psi2\sin\tfrac\theta2\sin\tfrac\phi2
\end{aligned}}
$$

> **怎么记住这四条？** 不要背，按结构拆：
>
> 1. **$a$ 项只有全 $\cos$ 与全 $\sin$ 两种**（符号都为正）：$a = c_1c_2c_3 + s_1s_2s_3$。
> 2. **$b, c, d$ 项各含一个 $\sin$**，位置就是对应的轴：
>    - $b$（对应 $i$、绕 $X$）：单独的 $\sin$ 是 $\sin\frac\phi2$（绕 $X$ 的角），乘 $\cos\frac\psi2\cos\frac\theta2$；
>    - $c$（对应 $j$、绕 $Y$）：单独的 $\sin$ 是 $\sin\frac\theta2$（绕 $Y$ 的角），乘 $\cos\frac\psi2\cos\frac\phi2$；
>    - $d$（对应 $k$、绕 $Z$）：单独的 $\sin$ 是 $\sin\frac\psi2$（绕 $Z$ 的角），乘 $\cos\frac\theta2\cos\frac\phi2$。
> 3. **第二个"三正弦"项的符号**：$b$ 的为负、$c$ 的为正、$d$ 的为负。这个符号取决于 $q_zq_yq_x$ 展开时三虚数乘积落到哪个单位上（$ijk = -1$ 那一条），**最稳妥的办法是拿 $\theta = 0$ 或 $\phi = 0$ 等特例代进去验一遍**，或者干脆用四元数乘法现算。

**（b）从旋转矩阵 $R$ 反解四元数**（工程里常用，也叫 Shepperd 方法）：若已经算出 $R$（例如 (3)），可以直接取

$$
\begin{aligned}
a &= \tfrac12\sqrt{1 + R_{11} + R_{22} + R_{33}}\\
b &= \tfrac12\sqrt{1 + R_{11} - R_{22} - R_{33}}\\
c &= \tfrac12\sqrt{1 - R_{11} + R_{22} - R_{33}}\\
d &= \tfrac12\sqrt{1 - R_{11} - R_{22} + R_{33}}
\end{aligned}
$$

再**用非对角元素定符号**：

$$\operatorname{sign}(b) = \operatorname{sign}(R_{32} - R_{23}),\quad
\operatorname{sign}(c) = \operatorname{sign}(R_{13} - R_{31}),\quad
\operatorname{sign}(d) = \operatorname{sign}(R_{21} - R_{12})$$

> 实机上不会真去开四个根号（$R_{11}\to1$ 时 $b,c,d$ 的根式会失去精度），而是**先比较 $R_{11}, R_{22}, R_{33}$ 哪个最大、再决定先算哪个分量**，其余分量由非对角元素相除得到。这一段是"数值稳定"的实现细节。

### 5. 万向锁在四元数→欧拉角这一步里是怎么冒出来的（重要）

C1 用的是 $\operatorname{atan}$ 那一套公式；如果照抄过来（用矩阵元素表示）

$$\psi = \arctan\frac{R_{21}}{R_{11}},\qquad \phi = \arctan\frac{R_{32}}{R_{33}},$$

当 $\theta \to \pm\frac\pi2$ 时 $\cos\theta \to 0$，于是 $R_{11}\to0$、$R_{21}\to0$、$R_{32}\to0$、$R_{33}\to0$ —— 两个式子都变成 $\arctan\frac00$，**分母同时消失**，解就"崩"了。

用四元数的公式看得更直接：$\theta = \pm\frac\pi2$ 时

$$
\cos\theta = 0 \ \Longrightarrow\ R_{11} = 1 - 2(c^2+d^2) \to 0,\qquad R_{21} = 2(bc + ad) \to 0 .
$$

若把它们也写成 $\tan\psi = R_{21}/R_{11}$ 的形式就会出现 $0/0$。（这就是 C1 里的万向锁现象，只是换成了四元数的语言。）

**为什么物理上必然丢自由度？** 把 $\theta = \frac\pi2$ 代入 (3)：$\sin\theta = 1$、$\cos\theta = 0$，

$$
R = \begin{pmatrix}
0 & \cos\psi\sin\phi - \sin\psi\cos\phi & \cos\psi\cos\phi + \sin\psi\sin\phi \\
0 & \sin\psi\sin\phi + \cos\psi\cos\phi & \sin\psi\cos\phi - \cos\psi\sin\phi \\
-1 & 0 & 0
\end{pmatrix}
= \begin{pmatrix}
0 & -\sin(\psi - \phi) & \cos(\psi-\phi) \\
0 & \cos(\psi-\phi) & \sin(\psi-\phi) \\
-1 & 0 & 0
\end{pmatrix}
$$

**整个矩阵只依赖 $(\psi - \phi)$ 这一个组合！** 也就是说 $\psi$ 和 $\phi$ 单独变化无法区分：$(\psi, \phi) = (0^\circ, 0^\circ)$ 与 $(\psi,\phi) = (40^\circ, -40^\circ)$ 给出**完全同一个姿态**。（这也解释了 C1 里调 yaw 和调 roll 得到的转动看起来一样。）

所以欧拉角在 $\theta = \pm\frac\pi2$ 处**只有 2 个有效自由度**，反解必然不唯一 —— 这不是公式选得不好，而是欧拉角这个参数化方式的**本质缺陷**（拓扑上，欧拉角是 $SO(3)$ 上的局部坐标卡，而 $SO(3)$ 无法用单张坐标卡覆盖）。

### 6. 实用小结

| 事项 | 结论 |
| --- | --- |
| 四元数要用哪一个 | 必须**单位四元数**（$\|q\| = 1$），否则 $q^{-1} = q^{*}$ 不成立、旋转也不纯粹 |
| 常用转换 | $\theta = \arcsin(2(ac - bd))$；$\psi = \operatorname{atan2}(2(ad+bc),\ 1-2(c^2+d^2))$；$\phi = \operatorname{atan2}(2(ab+cd),\ 1-2(b^2+c^2))$ |
| 符号一致性 | $q$ 与 $-q$ 是同一姿态：读数前先统一到 $a \ge 0$；做 SLERP/滤波前先判"是否同侧"（若 $q_1\cdot q_2 < 0$，就把其中一个取负） |
| 归一化 | 每步积分后重新归一化，抑制浮点误差累积：$\dot q = \frac12\,q\otimes[0,\vec\omega]$，一阶近似就是 $q \leftarrow q + \frac12\big(q\otimes[0,\vec\omega]\big)\Delta t$，再除以新模长。⚠️ **左乘还是右乘取决于 $\vec\omega$ 是机体系角速度还是地球系角速度**，用之前拿"纯偏航 $\omega_z$"验一遍：$\dot\psi = \omega_z$ 成立的那个写法才对 |
| 欧拉角 | **只在"给人看/给串级 PID 用"的时候才反解**，且必须面对 $\theta = \pm90^\circ$ 的奇点（实际飞行中要限幅或改用四元数/旋转矩阵做控制器内环） |
| 别忘了 C1 的物理出发点 | 传感器测到的是**机体系**下的量，要转成地球系：矩阵版是 $V_e = R_b^e\,V_b$，四元数版就是 $V_e = q\,[0,V_b]\,q^{*}$（两者表示同一个 $R_b^e$，别和 $R_e^b$ 弄混） |

> **本节要点一句话**：四元数把"姿态"放在 $S^3$ 上、乘法就是复合、没有奇点；欧拉角把"姿态"摊在三张坐标卡上、反解必然有万向锁。**转换的代价不在四元数，而在欧拉角。**
