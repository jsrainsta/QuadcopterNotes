# 四轴飞行器的 PID：从笔记到实机

> 配套文档：[PID.md](PID.md)（1D 小球模型的理论推导）· [pid-demo.html](pid-demo.html)（PID 可视化演示）
> 参考实现：学长项目 `Crabor-Quadcopter-8a036c8/Project/APP_FUNC/pid.c`、`IMU.c`

---

## 0. 这篇文档讲什么

你的 `PID.md` 用"1D 小球位置控制"讲清了 PID 的本质：P 是现在、I 是过去、D 是未来。那是**理想世界的控制**——被控量（位置）可以直接测量，执行机构（加速度）可以任意精确施加，干扰是恒定的重力。

但四轴飞行器不是这样。这篇文档把笔记里的同一个 PID 搬到真机上，回答三个问题：

1. 四轴的控制对象和"小球"到底是什么关系？
2. 同一个公式，到了四轴上发生了什么变化、为什么这样变？
3. 学长代码里的串级 PID、Ti/Td、积分限幅……和笔记公式是怎么对应的？

结论先行：**姿态控制的数学结构和笔记里的 1D 小球几乎一模一样（都是"二阶积分对象"），所以你的笔记直接适用；差别全部出在"测量"、"执行"和"工程细节"这三层**。

---

## 1. 快速回顾：笔记里的 PID（1D 小球）

笔记的核心链条：

- 被控量：位置 $x(t)$，目标 $x_0$，误差 $e(t)=x(t)-x_0$
- 能直接控制的量：加速度（升力）$a(t)$
- 控制器（笔记式，增益为负）：

$$a(t) = K_p \cdot e(t) + K_i \cdot \int_0^t e(\tau)\,d\tau + K_d \cdot \frac{de(t)}{dt} \qquad (K_p,K_i,K_d<0)$$

三个结论，后面都会用到：

| 控制方式 | 结果 | 原因 |
|---|---|---|
| 纯 P | **简谐运动**，永不停息 | $\ddot x = K_p(x-x_0)$，即弹簧振子，$\omega=\sqrt{-K_p}$ |
| PD | 阻尼，能停住 | D 项看速度，提前减速，吸收动能；Kd 太小过冲、太大"刹停" |
| PID | 消除稳态误差 | 恒定外力（重力）下 PD 会停在偏离处，I 项累积修正 |

注意一个细节：笔记里**误差的定义是"当前 − 目标"**（$e = x - x_0$），所以增益取负值才"把小球拉回目标"。这一点在后面第 5 节会和实机惯例对账。

## 2. 四轴的控制对象：和"小球"是同一个模型

### 2.1 姿态通道的动态方程

先看四轴绕一根轴（比如 roll）的转动。令 $\theta$ 为倾角，$I$ 为转动惯量，电机差速产生力矩 $M$：

$$M = I \cdot \ddot{\theta} \quad\Longrightarrow\quad \ddot{\theta} = \frac{M}{I}$$

小角度下，电机力矩近似与"左右电机转速差"成正比。也就是说：

> **力矩 → 角加速度 → 角速度 → 角度**，这是一个**二阶积分链**：
> $$\ddot{\theta} = u(t)$$

和笔记里 $\ddot{x} = a(t)$ **完全同构**。笔记里 $a$ 是"升力加速度"，四轴里 $u$ 是"角加速度"；笔记里 $x$ 是位置，四轴里 $\theta$ 是角度。位置/角度都是"加速度的二次积分"。

**所以笔记的全部结论可以直接移植**：

- 对角度只做 P 控制 → 飞机绕目标角度做简谐振荡（就像笔记里的纯 P 小球）；
- 加上角速度阻尼（D）→ 稳定停在目标角度；
- 这就是为什么姿态环必须同时"看角度"和"看角速度"。

### 2.2 但有一个本质区别：天然稳定性

- 笔记的小球：**不控制时也只是停着或匀速**，P 控制造成的振荡不致命；
- 四轴（特别是 pitch/roll）：**不控制时立刻倒**。重心在螺旋桨下方，倾斜后升力向量倾斜，飞机一边倒一边加速横移——控制回路**必须永远在线**，停一秒就坠机。

这带来第一个工程心态变化：**笔记可以"想清楚再控制"，四轴必须"先保证不死，再追求性能"**——所以实机代码里到处都是限幅、安全停机、模式状态机。

## 3. 差别一：反馈从哪来？（姿态估计）

这是笔记和实机**最大的认知差**。

### 3.1 笔记假设

笔记里 $x(t)$ 是"已知的"——直接就能测到小球在哪。

### 3.2 四轴的现实

四轴**没有任何传感器能直接测出角度**：

| 传感器 | 测什么 | 特性 |
|---|---|---|
| 陀螺仪（MPU6050） | 角速度 $\dot\theta$ | **快、准**，但积分会漂移（零偏累积） |
| 加速度计 | 重力向量方向 | 长期稳定（重力方向永远朝下），但振动噪声大，加速时会骗人 |
| 磁力计（HMC5883L） | 地磁场方向 | 只能辅助航向 yaw，受电机磁场干扰 |

所以实机的角度是"**估**"出来的，不是"测"出来的：陀螺仪积分提供高频姿态，加速度计/磁力计提供低频校正，两者用**互补滤波**（学长的 `IMU.c` 就是 Mahony 互补滤波，四元数形式）融合。

### 3.3 这给 PID 带来什么

1. **PID 吃的是"估计值"**：姿态估计延迟、噪声、抖动，直接进控制环。实机调 PID 时经常发现"参数调不动"，其实一半问题在姿态估计不干净（振动、滤波参数、零偏没校好）。
2. **信号质量决定环的带宽**：角速度（陀螺仪直接测）远比角度（解算出来的）干净，这是后面串级结构能成立的关键前提。
3. **必须做零偏校准**：上电静止采样取平均，把陀螺仪/加速度计/气压计的偏移扣掉（学长 `MPU6050_Offset()` 采 100 次）。笔记里没有这步——理想世界里传感器不出错。

> **学习要点**：姿态解算（Mahony/互补滤波）不是"可选项"，它是 PID 的上游。第三学期先做解算、用上位机确认角度又稳又跟手，再谈 PID。

## 4. 差别二：单环变串级（Cascade PID）

### 4.1 结构对比

```
笔记（单环）：     期望位置 ─→ PID ─→ 加速度 ─→ 小球位置
                              ↑
                         位置反馈（直接测得）

四轴（串级）：     期望角度 ─→ 外环P ─→ 期望角速度 ─→ 内环PD ─→ 电机力矩 ─→ 角度
                                 ↑                        ↑
                            角度反馈（解算）          角速度反馈（陀螺仪）
```

学长 `pid.c` 的对应实现（roll 轴）：

```c
// 外环：角度环，只有 P
shell->output = shell->Kp * shell->eK;          // Kp = 4.4，输出是"期望角速度"
// 内环：角速度环，PD（用 Ti/Td 表达，见第 5 节）
core->eK = shell->output - coreStatus;          // 期望角速度 - 实际角速度（陀螺仪）
core->output = core->Kp * (core->eK + core->eSum * coreKi + (core->eK - core->eK_1) * coreKd);
```

### 4.2 为什么要串级？三个理由

1. **抗扰动更快**：一阵风直接产生干扰力矩，最先影响的是**角速度**。内环盯着角速度，风一吹立刻反向出力把它压回去——根本来不及等角度变化再反应（外环如果直接控角度，要等"角度被吹歪了"才知道，慢了一个量级）。
2. **内环把对象"改造"得更好控**：内环（角速度环）控好之后，"期望角速度 → 实际角速度"几乎是 1:1 的快速跟随，外环面对的是一个"线性、干净"的积分对象，参数好调、鲁棒。
3. **信号质量的自然选择**：角速度是陀螺仪直接测的（干净），角度是解算出来的（有延迟有噪声）。让"脏"信号（角度）去决定"慢"的量（期望角速度），让"干净"信号（角速度）去决定"快"的量（力矩），各得其所。

### 4.3 和笔记的对应关系

笔记的"小球"相当于四轴的"角度"，笔记里"给速度加阻尼"的 D 项，在串级里被"内环角速度负反馈"天然实现了：内环本身就是 $\dot\theta$ 的负反馈，等效于给角度环提供了阻尼。**所以外环只需要 P 就够了**（这正是学长外环只给 Kp 的原因，下一节从稳态误差角度再证明一次）。

## 5. 差别三：符号约定与参数形式的"翻译"

这是最容易看晕的地方，因为笔记和实机代码**用了两套相反的习惯**。

### 5.1 误差方向与增益符号

| | 笔记 | 实机惯例（学长代码） |
|---|---|---|
| 误差定义 | $e = x - x_0$（当前 − 目标） | $e = \text{期望} - \text{实际}$（目标 − 当前） |
| 举例 | 小球在目标右边 → $e>0$ | 飞机左倾（实际角度为负）→ $e>0$ |
| 增益符号 | $K_p<0$（把误差"拉回来"） | $K_p>0$（同样把误差"拉回来"） |
| 学长代码 | — | `eK = expRoll - angle.roll; output = Kp * eK;` |

两者数学完全等价：定义 $e' = -e$，则笔记式 $a = K_p e$ 写成 $a = (-K_p)e'$，负增益自动变成正增益。**物理没变，只是坐标方向的定义不同**。以后读任何飞控代码，第一件事就是确认它的误差符号约定，否则正负号会把人折磨疯（学长的 TODO 注释里就有 yaw 正负号的坑）。

### 5.2 参数形式：Ki/Kd 形式 ↔ Ti/Td 形式

笔记用的是"增益"形式：

$$u = K_p\, e + K_i \textstyle\int e\,dt + K_d\, \dot e$$

学长（以及很多工业/飞控代码）用的是"时间常数"形式：

$$u = K_p \left( e + \frac{1}{T_i}\int e\,dt + T_d\, \dot e \right)$$

对照学长代码 `coreKi = pidT / core->Ti; coreKd = core->Td / pidT;` 和输出式，展开：

$$u = K_p\, e + \underbrace{\frac{K_p}{T_i}}_{K_i} \cdot \frac{\textstyle\sum e \cdot T}{1} + \underbrace{K_p T_d}_{K_d} \cdot \frac{\Delta e}{T}$$

两个形式的对应关系：

$$K_i = \frac{K_p}{T_i}, \qquad K_d = K_p \cdot T_d$$

> **这就是你笔记公式和学长代码之间唯一需要"翻译"的地方**：学长的 `Ti=0.5s, Td=0.08s, Kp=2.6` 等价于你笔记里的 $K_i = 2.6/0.5 = 5.2,\ K_d = 2.6\times0.08 = 0.208$。

$T_i$ 的物理含义：积分项用多长时间"追上"比例项（积分时间越短，I 越猛）；$T_d$ 是微分时间（预测未来多少时间后的误差）。工业 PID 惯例用 Ti/Td 是因为它们和整定表（Ziegler–Nichols）直接对应。

## 6. 差别四：连续公式 → 离散化实现

笔记里是连续积分、连续微分，实机是**每 1~5ms 跑一次**的离散循环。

### 6.1 离散化的三个式子

$$\begin{aligned}
\text{比例：} & \quad u_P[k] = K_p\, e[k] \\
\text{积分：} & \quad u_I[k] = K_i \sum_{j=0}^{k} e[j]\, T = K_i\, eSum[k] \qquad (eSum \mathrel{+}= e[k]\cdot T) \\
\text{微分：} & \quad u_D[k] = K_d\, \frac{e[k] - e[k-1]}{T}
\end{aligned}$$

其中 $T$ 是**采样周期，必须等于真实循环周期**。学长用 TIM4 测 `pidT = 定时器计数/1MHz` 就是干这个的——因为 RTOS 任务周期有抖动，$T$ 直接用固定值会让实际增益漂移。你们工程里已经初始化了 DWT 周期计数器，可以更精确地测。

### 6.2 离散化带来的三个经典坑（学长代码里都有）

1. **微分放大噪声**：$u_D = K_d \frac{\Delta e}{T}$，角度/角速度的每个噪声毛刺都会除以一个很小的 $T$ 被放大。对策：对测量值做低通滤波，或"微分先行"（只微分量测值不微分目标值，避免目标跳变时微分冲击）。学长直接裸差分（没滤波），这是他们代码的已知弱点。
2. **积分饱和（windup）**：执行机构有限幅（PWM 1000–2000），电机早就到极限了，积分还在累加，等你松手时积分"欠的账"会制造大过冲。对策就是学长代码里的**积分限幅 + 积分分离**：
   ```c
   // 学长 pid.c：eSum 超过 ±4000 时，只允许"往回拉"方向的积分继续累加
   if (core->eSum > CORE_INT_MAX) {
       if (core->eK < 0) core->eSum += core->eK;   // 误差反向时才继续积分
   } else if (core->eSum < -CORE_INT_MAX) {
       if (core->eK > 0) core->eSum += core->eK;
   } else {
       core->eSum += core->eK;
   }
   ```
3. **输出限幅**：PID 输出、最终 PWM 都要 `Limit()`（学长 `PID_OUT_MAX=500`、`PWM_OUT_MIN/MAX=1000/2000`）。笔记里没有限幅，因为理想执行机构无穷大；真机电机只有 1000~2000 这一段可用，超了就是白算。

### 6.3 一个完整的最小离散 PID（可对照学长 `PID_Calc` 读）

```c
typedef struct {
    float Kp, Ti, Td;      // 比例增益、积分时间、微分时间
    float eK, eK_1;        // 本次误差、上次误差
    float eSum;            // 误差积分（带限幅）
    float output;
} PID_t;

float PID_Update(PID_t *p, float setpoint, float actual, float T) {
    float eK  = setpoint - actual;        // 实机惯例：目标 − 实际
    p->eSum += eK * T;                    // 积分（可加积分限幅/分离）
    p->eSum = Limit(p->eSum, -INT_MAX, INT_MAX);

    float dE  = (eK - p->eK_1) / T;       // 微分（可对量测值滤波）
    p->output = p->Kp * (eK + p->eSum / p->Ti + dE * p->Td);
    p->output = Limit(p->output, -OUT_MAX, OUT_MAX);

    p->eK_1 = eK;
    return p->output;
}
```

## 7. 差别五：I 项去哪了？（稳态误差的新理解）

### 7.1 笔记的稳态误差

笔记：恒定重力下，PD 的稳态加速度输出被重力"吃掉"一部分，剩下 $e_{ss} = -g/K_p$ 消不掉，必须加 I。**误差发生在"位置层"，I 也在位置环里**。

### 7.2 四轴的稳态误差

四轴姿态也有"恒定干扰"，但形式不同——是**恒定干扰力矩** $\tau_d$：重心偏置、桨叶不平衡、持续的风。它的作用点在**角速度层**。

看串级结构稳态会发生什么（设期望角度 $\theta_d$ 固定）：

1. 若 $\theta \ne \theta_d$，外环输出 $\omega_d = K_p(\theta_d-\theta) \ne 0$；
2. 内环会把 $\omega$ 拉到 $\omega_d$，飞机继续转动，$\theta$ 持续变化；
3. 所以稳态时必然 $\theta = \theta_d$，且 $\omega = \omega_d = 0$；
4. 内环要"顶住"干扰力矩 $\tau_d$，靠的是它的**积分项**（$eSum$ 累积出恒定输出恰好抵消 $\tau_d$）。

**结论：恒定干扰被内环（角速度环）的 I 项吸收了，所以外环（角度环）只需要 P，不需要 I。** 学长代码里内环给了 `Ti=0.5`，外环只给了 `Kp`，就是这个道理。

### 7.3 和笔记的有趣对照

| | 笔记（1D 小球） | 四轴姿态（串级） |
|---|---|---|
| 恒定干扰 | 重力（作用在"加速度层"） | 干扰力矩（作用在"角速度层"） |
| 谁负责抵消 | 位置环自己的 I | 内环（角速度环）的 I |
| 外环/位置环要不要 I | 要 | **不要（P 就够）** |

笔记里"PD 有稳态误差所以加 I"的教训，在四轴上以另一种方式兑现了：**I 没有消失，只是搬家到了内环**。高度环又不一样——气压计高度控制类似笔记，恒定升力损失会带来高度稳态误差，所以高度环（学长的 `thrShell`，Kp=1.0）如果启用，往往要配 I 或者靠积分修正，这也是学长把高度环单独列出来的原因。

## 8. 差别六：从 1 个量到 4 个通道（混控）

### 8.1 四轴的"控制通道"

笔记只有 1 个被控量；四轴有 4 个：**roll、pitch、yaw 三个姿态 + 总油门（高度）**。而执行机构只有 4 个电机。所以控制器输出（3 个姿态 PID + 1 个油门）要先"混控"成 4 路电机指令。

### 8.2 X 型机架混控公式（学长 `Motor_Calc`）

```c
motor1 = Limit(thr - pitch + roll - yaw, 1000, 2000);   // 右前
motor2 = Limit(thr - pitch - roll + yaw, 1000, 2000);   // 右后
motor3 = Limit(thr + pitch + roll + yaw, 1000, 2000);   // 左后
motor4 = Limit(thr + pitch - roll - yaw, 1000, 2000);   // 左前
```

物理意义：

- **pitch/roll**：对角电机差速产生倾覆力矩 → 倾斜 → 水平移动；
- **yaw**：四电机分两组反向旋转，靠**反扭矩差**转机头（所以混控里 yaw 的符号是 +−+− 交错）；
- **thr**：四路同加，是"基准油门"，姿态 PID 的输出都叠加在它上面。

注意通道间的**耦合**：改油门会同时影响姿态响应，机架振动会同时污染三个轴——所以调参时要"先定油门、再逐个轴调"。

### 8.3 安全逻辑是混控的"外包装"

笔记不需要安全；实机必须有（学长代码里的体现）：

- 油门过低（`expMode <= 1050`）或倾角超限（`|roll/pitch| > 65°`）→ 四电机全部拉到最低，**直接停**；
- 上电时电机先以最低占空比停 5 秒（电调"初始化/解锁"流程，学长启动任务里的 `TIM3->CCR=54`）；
- 遥控信号异常（超出 900~2100μs）→ 兜底值。

> 你们的 `MotorTask` 目前是"油门直通四电机"（无混控、无停机逻辑），第三学期要把这一整段替换成"姿态 PID 输出 + 混控 + 安全逻辑"。

## 9. 差别七：调参的现实

### 9.1 笔记：参数可以"算出来"

笔记里纯 P 有解析解 $\omega = \sqrt{-K_p}$，Kp、Kd 可以精确推导。因为对象模型（牛顿第二定律）是完全已知的。

### 9.2 四轴：对象模型不精确，只能"试出来"

真机的 $\ddot\theta = u$ 只是近似：电机有响应延迟（一阶惯性），螺旋桨气动效应非线性，机架有弹性振动，电池电压下降会让电机响应变化。**Kp 该给多少，理论算不准，只能实验整定**。

实机调参的方法论（和你的 `pid-demo.html` 完全同构，只是要拆桨/固定机架！）：

1. **先内环后外环**：先把角速度环调稳（只动内环，看陀螺仪角速度是否快速跟手、无振荡），再调外环角度环；
2. **先 P 后 D 再 I**：P 给到"开始轻微振荡"再回调 60~70%（对应你演示里纯 P 的简谐运动——实机上出现等幅振荡就是 P 过头了）；再加 D 消除过冲（对应你演示里"Kd 太小过冲、太大刹停"）；最后加 I 消稳态误差；
3. **经典整定法**：临界比例法（只留 P，加大到等幅振荡，记录临界增益和周期，按 Ziegler–Nichols 表算 Ti/Td）、衰减曲线法；
4. **用演示工具练手感**：`pid-demo.html` 里调 Kp/Kd/Ki 看到的现象（振荡频率随 Kp、阻尼随 Kd、稳态误差被 I 消除），实机上完全一样——先在工具里建立直觉，再去实机省大量炸机。

### 9.3 实机调参的"脏活"清单

- 拆桨或把机架固定在台钳上（否则参数一过冲就起飞/打人）；
- 用上位机录"设定值 vs 实际值"曲线，不要凭眼睛看飞机；
- 零偏校准不干净会让角度有常数偏差 → 误以为稳态误差，误加 I；
- 采样周期抖动（RTOS 任务抢占）会让实际增益漂移 → 用 DWT/定时器实测 $T$。

## 10. 总对照表：笔记 vs 四轴实机

| 维度 | 笔记（1D 小球） | 四轴实机 |
|---|---|---|
| 被控量 | 位置 $x$ | 姿态角（roll/pitch/yaw）+ 高度 |
| 对象模型 | $\ddot x = a$（双积分，精确已知） | $\ddot\theta = u$（近似，有电机延迟/非线性） |
| 反馈 | 位置直接测量 | 陀螺仪+加速度计+磁力计 → **姿态解算估计** |
| 控制结构 | 单环 | **串级**（外环角度 P → 内环角速度 PD） |
| 通道数 | 1 | 4（roll/pitch/yaw/throttle）+ 混控 |
| 误差符号 | $e = x - x_0$，增益为负 | $e =$ 期望 $-$ 实际，增益为正 |
| 参数形式 | $K_i, K_d$ | 常为 $T_i, T_d$（$K_i=\frac{K_p}{T_i},\ K_d=K_p T_d$） |
| 时间尺度 | 秒级 | 毫秒级（姿态环 1~5ms） |
| 稳定性 | 天然稳定（振荡但可控） | **天然不稳定**，控制必须永远在线 |
| 干扰 | 恒定重力 | 干扰力矩（重心偏、风、桨不平衡） |
| 稳态误差 | 位置环加 I 消除 | **内环 I 吸收，外环无需 I** |
| 输出 | 加速度（无限幅） | PWM（1000~2000，必须限幅） |
| 参数整定 | 解析可算 | 实验整定（先内后外、先 P 后 D 再 I） |
| 额外工程 | 无 | 零偏校准、积分抗饱和、安全停机、模式状态机 |
