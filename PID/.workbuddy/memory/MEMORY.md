## 硬性约定
1. **单文件离线 HTML**：不用 CDN / 外部库 / 构建步骤，双击直接打开。
2. **深色主题**，高对比、大字号（投影讲课用）。
3. 物理统一：`I = 1` 归一化，角度**用度(°)**，角速度 °/s，角加速度 °/s²。
4. 控制律：`M = Kp·e + Ki·∫e dτ − Kd·ω + M_dist`，其中 `e = θ目标 − θ实际`。
   - 等价经典形式：`M = Kp·e + Ki·∫e + Kd·(de/dt)`（因 `de/dt = −ω`）——用户笔记里会问“为什么 Kp 正、Kd 负”，答案即此。
5. 判据：`ωn = √(Kp/I)`，`ζ = Kd/(2√(Kp·I))`，`Kd_临界 = 2√(Kp·I)`。
6. 预设剧情要正好复现笔记三个结论：纯P等幅振荡 → Kd 调欠/临界/过阻尼 → 恒值扰动下 PD 有稳态误差 `e=M_bias/Kp` → 加 I 消静差。
7. 中文界面，术语与笔记一致（滚转 Roll φ / 俯仰 Pitch θ / 偏航 Yaw ψ）。
